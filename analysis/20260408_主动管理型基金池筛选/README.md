# 主动管理型基金池筛选

## 需求背景
按第十条筛选逻辑，从普通股票型、偏股混合型、灵活配置型三类基金中筛选符合条件的主动管理型基金，输出初选池。

## 交付要求
- 规模报告期：2025-12-31（年报）
- 业绩截止日：2026-04-08
- 筛选条件：
  1. 基金公司主动权益规模 ≥50亿 且 行业排名前50%
  2. 单只基金规模 ≥2亿
  3. 基金经理公开历史业绩累计 ≥1年（跨产品）
  4. 仅开放申购基金
- 打分权重：长期超额65% + 短期超额15% + 最大回撤10% + 夏普10%
- 入池规则：全市场及各赛道分别取综合得分前50%

## 输出文件
- `data/active_fund_pool.xlsx`（5个 Sheet）
  - Sheet1：基金数量统计
  - Sheet2：基金公司规模
  - Sheet3：全量三类基金
  - Sheet4：基础筛选后
  - Sheet5：初选池-全市场50%

## 备注
- 赛道来源：Oracle `tytfund.tb_fd_equity_topic`，未收录归"全市场"
- 主动权益定义：三类基金中近4个季报股票仓位均值 ≥60%
