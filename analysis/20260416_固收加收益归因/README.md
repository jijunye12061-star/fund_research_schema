# 固收+基金 Brinson 大类资产收益归因

## 需求背景
将固收+基金按波动程度分为四类（低波/中波/高波/转债），每类计算大类资产（股票/转债/纯债）
基准权重，进行 Brinson 归因分解，评估配置、选券和交易能力。

## 方法概要

### Step 1: 波动分类
- 转债基金：`c_type2_code='002001'` 直接归类
- 低波固收+：近一期 股票 + 转债/2 < 5%
- 高波固收+：近一期 股票仓位 > 40%
- 核心样本：含权仓位 + 近1年波动率 + 近1年最大回撤 等权排名，1:1:1 分为高波/中波/低波

### Step 2: 基准权重
每类取近四期平均仓位（转债/股票/纯债）→ 归一化为基准权重

### Step 3: Brinson 归因
- 重定义季度：Q1=2/14-5/15, Q2=5/16-8/15, Q3=8/16-11/15, Q4=11/16-2/13
- 持仓假设：季报持仓前后 45 天不变，季报期按比例放大（隐含于归一化）
- 基准指数：沪深300 / 中证转债 / 中债新综合财富指数
- 归因分解：绝对收益 = 超额 + 基准；超额 = 配置 + 选券 + 交易

## 交付要求
- 分析期间：2024-02-08 ~ 2026-01-27（8 个重定义季度）
- 输出粒度：每只基金一行，八期简单加总
- 胜率统计：转债投资战胜指数胜率、正收益概率

## 输出文件
- `data/固收加收益归因.xlsx`
  - Sheet 1: 归因汇总（每基金一行）
  - Sheet 2: 季度明细（每基金×每季度一行）
  - Sheet 3: 基准权重（每类×每季度）
