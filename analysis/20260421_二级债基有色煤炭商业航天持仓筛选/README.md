# 二级债基有色+煤炭+商业航天持仓筛选

## 需求背景

筛选权益持仓中涉及有色金属、煤炭行业或商业航天概念的二级债基，按合计权重降序排列，评估相关主题的敞口分布。

## 筛选条件

- **基金类型**：混合债券型二级基金（`c_class3_code = '003002002'`）
- **基金状态**：已成立满 6 个月且未终止
- **报告期**：2025-12-31（年报全持仓，`c_style IN ('02','04')`）
- **持仓快照**：行业归属和商业航天概念均取 2025-12-31 当日快照

## 权重口径

统一使用 `c_nav_ratio`（占净值比，%），基于全持仓数据：

| 字段 | 来源 | 说明 |
|------|------|------|
| 有色金属权重 | `tb_fd_portfolio_stk` + `tb_stk_industry` + `tb_dict_params` | 持有中信一级行业"有色金属"的股票占净值比合计 |
| 煤炭权重 | 同上 | 持有中信一级行业"煤炭"的股票占净值比合计 |
| 商业航天权重 | `tb_fd_portfolio_stk` + `tb_stk_concept` | 持有概念代码 007356 的股票占净值比合计 |
| 合计权重 | 三类股票并集去重 | 因行业/概念有重叠，合计 ≤ 三者相加之和 |

## 输出文件

- `data/二级债基有色煤炭商业航天持仓.xlsx`

## 备注

- 主代码去重：`c_init_code = c_fd_code OR c_init_code IS NULL`
- 港股持仓无中信行业归属，不计入有色/煤炭权重（对二级债基影响极小）
- 结果含所有至少有一类持仓 > 0 的基金，不设最低门槛
