# 双重任务基金经理筛选

## 需求背景
识别同时管理主动权益基金（type2_code=001001）和二级债基的基金经理，便于了解"股债双栖"经理的管理情况。

## 交付要求
- 筛选条件：二级债基（c_class3_name='混合债券型二级基金'，未清盘）+ 主动权益基金（type2=001001，未清盘）取交集经理
- 规模报告期：2025-12-31（年报）
- 业绩区间：今年以来（c_period_code='07'，截至 2026-04-08）
- 输出字段：基金经理 | 权益基金代码/名称 | 二级债基代码/名称 | 规模(亿) | 今年以来收益率 | 最大回撤

## 输出文件
- `data/dual_mandate_managers.xlsx`

## 备注
- 多经理共管基金已展开为每行一人
- 权益基金代码/名称按经理聚合为逗号分隔字符串
