# 基金经理变动分析

## 需求背景
统计股票型/混合型/债券型基金（已成立未清盘、主代码）的基金经理变动情况，输出两个维度。

## 交付要求

### Sheet 1：基金经理变动明细（基金维度）
- 筛选：tb_fd_basic_info.c_class1_code IN ('001','002','003')，未清盘，主代码
- 字段：代码 / 名称 / 开始时间 / 结束时间（在任留空）/ 基金经理
- 仅含正式基金经理（c_post='基金经理'），排除助理和代理

### Sheet 2：基金经理汇总（经理维度）
- 范围：当前在任且管理至少一只上述基金的经理
- 数量统计（均为当前在管、主代码）：
  - 管理主动权益基金数量：tb_fd_category.c_type2_code='001001'，限股票型/混合型/债券型
  - 管理权益基金数量（含指数指增）：c_type1_code='001'，限股票型/混合型/债券型
  - 管理含权基金总数量：c_type1_code IN ('001','002','004')，限股票型/混合型/债券型
  - 管理基金总数量：所有类型
- 最长任期：当前在管基金中任期最长的（限股票型/混合型/债券型）
- 最长独立任期：当前在管基金中独立管理（无共管经理）时间最长的

### Sheet 3：经理变动分类（基金维度）
- 统计起点：2024-12-31
- 比较期初经理集合（CUT_DATE 在任）与期末经理集合（当前在任）
- 分类规则：
  - 完全未变：期初 = 期末（含中间换了但最终结果一致）
  - 仅新增：期初经理全部留任 + 新增了经理
  - 部分更替：有人离任但至少一人留任
  - 完全更换：期初经理全部离任
  - 期间新成立：成立日 > 2024-12-31
- 字段：基金代码 / 基金名称 / 变动类型 / 期初经理 / 期末经理 / 新增经理 / 离任经理

## 输出文件
- `data/基金经理变动分析.xlsx`（三个 sheet）
