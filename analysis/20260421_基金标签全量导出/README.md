# 基金标签全量导出

## 需求背景
按基金类型（权益/固收+/债券/混合）分 Sheet 导出最新标签数据，用于基金研究和展示。

## 交付要求
- 报告期：修改 `query.py` 第 17 行 `REPORT_DATE`
- 输出字段：各类型基金的产品信息 + 全量标签（仅保留标签字段，去掉原始分数）

## 输出文件
- `data/基金标签全量_{REPORT_DATE}.xlsx`（4 个 Sheet）

## Sheet 说明

| Sheet | 基金范围 | 主要维度 |
|-------|---------|---------|
| 权益基金 | type1=001 | 仓位/区域板块/风格/组合/交易 |
| 固收+基金 | type1=002 | 资产配置/债券风格/转债风格/权益标签 |
| 债券基金 | type1=003 | 券种/信用/久期/杠杆 |
| 混合基金 | type1=004 | 股债配置/区域板块/风格/债券风格 |

## 运行方式

```bash
python analysis/20260421_基金标签全量导出/query.py
```

## 备注
- `规模` 字段为 `tb_fd_basic_info.c_asset_net` 原始值，需确认单位
- 转债风格标签（CB 系列）仅对近 8 期转债仓位均值 ≥1% 的基金有值
