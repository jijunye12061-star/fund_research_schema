# tb_fd_tag_bd_style - 债券投资风格标签表

## 基本信息

- **主键**: (c_report_date, c_fd_code)
- **更新频率**: 季度
- **适用范围**: 一级分类为权益(001)、固收+(002)、债券(003)、混合(004)的初始基金，成立满两年

## 字段清单

|------------------|-------------|--------|----------------|

| c_fd_code        | VARCHAR(20) | 基金代码   | 六位代码           |

## 券种分类定义

各类债券占比的分子定义如下，分母统一为**债券市值合计**（`c_bd_total_mv`）：

| 券种  | 包含的债券类型                     | 对应 tb_fd_asset_allocation 字段                                                 |
|-----|-----------------------------|------------------------------------------------------------------------------|
| 利率债 | 国债、政策性金融债、央行票据、地方政府债        | c_bd_treasury_mv + c_bd_policy_mv + c_bd_central_bank_mv + c_bd_local_gov_mv |
| 信用债 | 企业债、中期票据、企业短期融资券、资产支持证券     | c_bd_corporate_mv + c_bd_mtn_mv + c_bd_short_term_mv + c_other_abs_mv        |
| 金融债 | 金融债（含政策性金融债）+ 同业存单 - 政策性金融债 | c_bd_financial_mv + c_bd_deposit_cert_mv - c_bd_policy_mv                    |

> 注：金融债字段(`c_bd_financial_mv`)包含政策性金融债，需减去政策性金融债(`c_bd_policy_mv`)得到商业金融债。

## 枚举值

### 券种风格标签 (c_bd_type_style) — 三分类模式

| 取值          | 判断逻辑                               |
|-------------|------------------------------------|
| 利率风格        | 利率债仓位均值 ≥70%                       |
| 信用风格        | 信用债仓位均值 ≥70%                       |
| 金融风格        | 金融债仓位均值 ≥70%                       |
| 利率+金融风格     | 利率债+金融债 ≥80%（未满足上述单一≥70%）          |
| 信用+金融风格     | 信用债+金融债 ≥80%，且 0.66 ≤ 信用/金融比 ≤ 1.5 |
| 信用+金融风格-偏金融 | 信用债+金融债 ≥80%，且 信用/金融比 < 0.66       |
| 信用+金融风格-偏信用 | 信用债+金融债 ≥80%，且 信用/金融比 > 1.5        |
| 均衡配置        | 其他                                 |

> 判断顺序：先检查单一风格(≥70%)，再检查混合风格(≥80%)，均不满足则为均衡配置。

### 券种择时标签 (c_bd_type_timing)

| 取值  | 判断逻辑                            |
|-----|---------------------------------|
| 择时  | min(利率债仓位变动均值, 信用债仓位变动均值) ≥ 10% |
| 不择时 | 其他                              |

### 杠杆偏好标签 (c_leverage_pref)

| 取值  | 判断逻辑（定开基金）     | 判断逻辑（非定开基金）    |
|-----|----------------|----------------|
| 高杠杆 | 杠杆率均值 > 1.6    | 杠杆率均值 > 1.3    |
| 中杠杆 | 1.2 < 均值 ≤ 1.6 | 1.1 < 均值 ≤ 1.3 |
| 低杠杆 | 杠杆率均值 ≤ 1.2    | 杠杆率均值 ≤ 1.1    |

### 杠杆择时标签 (c_leverage_timing)

| 取值  | 判断逻辑（定开基金）     | 判断逻辑（非定开基金）    |
|-----|----------------|----------------|
| 择时  | 杠杆率变动均值 ≥ 0.15 | 杠杆率变动均值 ≥ 0.10 |
| 不择时 | 其他             | 其他             |

> 注：杠杆率变动均值为**绝对值**变动（如从1.2变至1.4，变动=0.2），非百分比变化率。

### 信用偏好标签 (c_credit_pref)

| 取值    | 判断逻辑            |
|-------|-----------------|
| 信用下沉  | 低信用评级占比均值 ≥ 40% |
| 中高信用  | 高信用评级占比均值 ≥ 40% |
| 无明显偏好 | 其他              |

### 信用择时标签 (c_credit_timing)

| 取值  | 判断逻辑            |
|-----|-----------------|
| 择时  | 低信用评级变动均值 ≥ 10% |
| 不择时 | 其他              |

### 久期偏好标签 (c_duration_pref)

| 取值   | 判断逻辑         |
|------|--------------|
| 长久期  | 久期均值 ≥ 3年    |
| 中长久期 | 2年 ≤ 均值 < 3年 |
| 中短久期 | 1年 ≤ 均值 < 2年 |
| 短久期  | 久期均值 < 1年    |

### 久期择时标签 (c_duration_timing)

| 取值  | 判断逻辑        |
|-----|-------------|
| 择时  | 久期变动均值 ≥ 1年 |
| 不择时 | 其他          |

## 数据来源

| 维度   | 数据源                    | 回溯期     | 关键字段                                            |
|------|------------------------|---------|-------------------------------------------------|
| 券种风格 | tb_fd_asset_allocation | 近8个季报期  | 各券种市值字段 / c_bd_total_mv                         |
| 杠杆风格 | tb_fd_asset_allocation | 近8个季报期  | c_fund_total_asset / c_fund_nav_total           |
| 信用风格 | tb_fd_bd_risk_metric   | 近4个半年报期 | c_high_credit_ratio, c_low_credit_ratio         |
| 久期风格 | tb_fd_bd_risk_metric   | 近4个半年报期 | c_duration                                      |
| 定开状态 | tb_fd_basic_info       | 当前      | c_regular_open_status                           |
| 基金范围 | tb_fd_category         | 当期      | c_type1_code IN ('001','002','003','004')，仅初始基金 |

## 注意事项

- 仓位占比为**券种内占比**（如利率债市值/债券总市值×100），非净值占比
- 变动均值 = 近N期环比变动绝对值的算术平均（`diff().abs().mean()`）
- 杠杆率为绝对值（如1.3），杠杆变动也是绝对值（如0.15），非百分比
- 基金需成立满两年（覆盖近八期季报）方可计算
- 定开基金与非定开基金使用不同的杠杆阈值
- 信用评级和久期仅半年报披露，故回溯4期≈2年
- 资产配置表存在同一基金同一报告期多条记录（不同c_style），取c_style最小的记录
- 无债券持仓（c_bd_total_mv=0）的基金不计算券种风格
- 信用/久期维度与券种/杠杆维度独立计算，outer merge合并；部分基金可能仅有部分维度标签

## 使用示例

```sql
-- 查询某报告期全部风格标签
SELECT c_fd_code,
       c_bd_type_style,
       c_bd_type_timing,
       c_leverage_pref,
       c_leverage_timing,
       c_credit_pref,
       c_credit_timing,
       c_duration_pref,
       c_duration_timing
FROM tytdata.tb_fd_tag_bd_style
WHERE c_report_date = '2024-09-30';

-- 筛选高杠杆+信用下沉的基金
SELECT c_fd_code, c_leverage_avg, c_low_credit_avg
FROM tytdata.tb_fd_tag_bd_style
WHERE c_report_date = '2024-09-30'
  AND c_leverage_pref = '高杠杆'
  AND c_credit_pref = '信用下沉';

-- 按定开/非定开分组统计杠杆水平
SELECT c_is_locked_fund,
       c_leverage_pref,
       COUNT(*) AS cnt
FROM tytdata.tb_fd_tag_bd_style
WHERE c_report_date = '2024-09-30'
GROUP BY c_is_locked_fund, c_leverage_pref;
```
