# tb_fd_tag_bd_style - 债券投资风格标签表

## 基本信息

- **主键**: (c_report_date, c_fd_code)
- **更新频率**: 季度
- **适用范围**: 一级分类为权益(001)、固收+(002)、债券(003)、混合(004)的主代码基金
- **前置条件**: 基金成立日早于回溯最早报告期（覆盖近八期季报 ≈ 2年）

## 字段清单

### 主键与控制字段

| 字段名           | 类型          | 注释   | 说明               |
|---------------|-------------|------|------------------|
| c_report_date | DATE        | 报告日期 | 季报截止日            |
| c_fd_code     | VARCHAR(20) | 基金代码 | 六位代码             |
| c_is_locked   | VARCHAR(10) | 是否定开 | '1'是/'0'否，影响杠杆阈值 |
| c_updatetime  | DATETIME(6) | 更新时间 | 系统自动生成           |

### 券种风格（近八期季报）

数据源: `tb_fd_asset_allocation` (各券种市值字段)，回溯近8个报告期（2年）

> 仓位占比为**券种内占比** = 各券种市值 / 债券总市值 × 100，非占净值比例

**券种三分类定义：**

- 利率债 = 国债(`c_bd_treasury_mv`) + 政策性金融债(`c_bd_policy_mv`) + 央行票据(`c_bd_central_bank_mv`) + 地方政府债(
  `c_bd_local_gov_mv`)
- 信用债 = 企业债(`c_bd_corporate_mv`) + 中期票据(`c_bd_mtn_mv`) + 企业短融(`c_bd_short_term_mv`) + 资产支持证券(
  `c_other_abs_mv`)
- 金融债 = 金融债(`c_bd_financial_mv`) - 政策性金融债(`c_bd_policy_mv`) + 同业存单(`c_bd_deposit_cert_mv`)

| 字段名                 | 类型            | 注释           | 说明                |
|---------------------|---------------|--------------|-------------------|
| c_rate_bd_pos_avg   | DECIMAL(10,4) | 利率债仓位均值(%)   | 近八期季报算术均值         |
| c_credit_bd_pos_avg | DECIMAL(10,4) | 信用债仓位均值(%)   | 近八期季报算术均值         |
| c_fin_bd_pos_avg    | DECIMAL(10,4) | 金融债仓位均值(%)   | 近八期季报算术均值         |
| c_rate_bd_chg_avg   | DECIMAL(10,4) | 利率债仓位变动均值(%) | 近八期季报环比变动绝对值的算术均值 |
| c_credit_bd_chg_avg | DECIMAL(10,4) | 信用债仓位变动均值(%) | 近八期季报环比变动绝对值的算术均值 |
| c_fin_bd_chg_avg    | DECIMAL(10,4) | 金融债仓位变动均值(%) | 近八期季报环比变动绝对值的算术均值 |
| c_bd_type_style     | VARCHAR(30)   | 券种风格标签       | 见枚举值              |
| c_bd_type_timing    | VARCHAR(10)   | 券种择时标签       | 见枚举值              |

### 杠杆风格（近八期季报）

数据源: `tb_fd_asset_allocation` (c_fund_total_asset / c_fund_nav_total)，回溯近8个报告期（2年）

> 杠杆率 = 基金总资产 / 基金净资产，为绝对值（如1.3），非百分比

| 字段名                | 类型            | 注释        | 说明                       |
|--------------------|---------------|-----------|--------------------------|
| c_leverage_avg     | DECIMAL(10,4) | 杠杆率均值     | 近八期季报算术均值，绝对值            |
| c_leverage_chg_avg | DECIMAL(10,4) | 杠杆率绝对变动均值 | 近八期季报环比变动绝对值的算术均值（如0.15） |
| c_leverage_pref    | VARCHAR(10)   | 杠杆偏好标签    | 见枚举值，定开/非定开使用不同阈值        |
| c_leverage_timing  | VARCHAR(10)   | 杠杆择时标签    | 见枚举值                     |

### 信用风格（近四期半年报）

数据源: `tb_fd_bd_risk_metric` (c_high_credit_ratio, c_low_credit_ratio)，回溯近4个半年报期（2年）

> 仅在半年报(06-30)和年报(12-31)披露，"近四期"指近4个半年报期

| 字段名                  | 类型            | 注释           | 说明                 |
|----------------------|---------------|--------------|--------------------|
| c_high_credit_avg    | DECIMAL(10,4) | 高信用评级占比均值(%) | 近四期半年报算术均值         |
| c_low_credit_avg     | DECIMAL(10,4) | 低信用评级占比均值(%) | 近四期半年报算术均值         |
| c_low_credit_chg_avg | DECIMAL(10,4) | 低信用评级变动均值(%) | 近四期半年报环比变动绝对值的算术均值 |
| c_credit_pref        | VARCHAR(10)   | 信用偏好标签       | 见枚举值               |
| c_credit_timing      | VARCHAR(10)   | 信用择时标签       | 见枚举值               |

### 久期风格（近四期半年报）

数据源: `tb_fd_bd_risk_metric` (c_duration)，回溯近4个半年报期（2年）

> 久期基于利率敏感性分析反推，仅在半年报(06-30)和年报(12-31)披露

| 字段名                | 类型            | 注释        | 说明                 |
|--------------------|---------------|-----------|--------------------|
| c_duration_avg     | DECIMAL(10,4) | 久期均值(年)   | 近四期半年报算术均值         |
| c_duration_chg_avg | DECIMAL(10,4) | 久期变动均值(年) | 近四期半年报环比变动绝对值的算术均值 |
| c_duration_pref    | VARCHAR(10)   | 久期偏好标签    | 见枚举值               |
| c_duration_timing  | VARCHAR(10)   | 久期择时标签    | 见枚举值               |

## 枚举值

### 券种风格标签 (c_bd_type_style) — 三分类模式

| 取值          | 判断逻辑                               |
|-------------|------------------------------------|
| 利率风格        | 利率债仓位均值 ≥70%                       |
| 信用风格        | 信用债仓位均值 ≥70%                       |
| 金融风格        | 金融债仓位均值 ≥70%                       |
| 利率+金融风格     | 利率债+金融债 ≥80%（且不满足上述单一风格）           |
| 信用+金融风格     | 信用债+金融债 ≥80%，且 0.66 ≤ 信用/金融比 ≤ 1.5 |
| 信用+金融风格-偏金融 | 信用债+金融债 ≥80%，且信用/金融比 < 0.66        |
| 信用+金融风格-偏信用 | 信用债+金融债 ≥80%，且信用/金融比 > 1.5         |
| 均衡配置        | 其他                                 |

### 券种择时标签 (c_bd_type_timing)

| 取值  | 判断逻辑                               |
|-----|------------------------------------|
| 择时  | 三个券种变动均值中第二大的值 ≥ 10%（即至少两个维度有显著变动） |
| 不择时 | 其他                                 |

### 杠杆偏好标签 (c_leverage_pref)

| 取值  | 定开基金 (c_is_locked='1') | 非定开基金 (c_is_locked='0') |
|-----|------------------------|-------------------------|
| 高杠杆 | 杠杆率均值 > 1.6            | 杠杆率均值 > 1.3             |
| 中杠杆 | 1.2 < 均值 ≤ 1.6         | 1.1 < 均值 ≤ 1.3          |
| 低杠杆 | 杠杆率均值 ≤ 1.2            | 杠杆率均值 ≤ 1.1             |

### 杠杆择时标签 (c_leverage_timing)

| 取值  | 定开基金             | 非定开基金            |
|-----|------------------|------------------|
| 择时  | 杠杆率绝对变动均值 ≥ 0.15 | 杠杆率绝对变动均值 ≥ 0.10 |
| 不择时 | 其他               | 其他               |

### 信用偏好标签 (c_credit_pref)

> 优先级: 信用下沉 > 中高信用（若两者同时满足，标为"信用下沉"，因为低评级暴露更能反映风险特征）

| 取值    | 判断逻辑            |
|-------|-----------------|
| 信用下沉  | 低信用评级占比均值 ≥ 40% |
| 中高信用  | 高信用评级占比均值 ≥ 40% |
| 无明显偏好 | 其他              |

### 信用择时标签 (c_credit_timing)

| 取值  | 判断逻辑            |
|-----|-----------------|
| 择时  | 低信用评级变动均值 ≥ 10% |
| 不择时 | 其他              |

### 久期偏好标签 (c_duration_pref)

| 取值   | 判断逻辑         |
|------|--------------|
| 长久期  | 久期均值 ≥ 3年    |
| 中长久期 | 2年 ≤ 均值 < 3年 |
| 中短久期 | 1年 ≤ 均值 < 2年 |
| 短久期  | 久期均值 < 1年    |

### 久期择时标签 (c_duration_timing)

| 取值  | 判断逻辑        |
|-----|-------------|
| 择时  | 久期变动均值 ≥ 1年 |
| 不择时 | 其他          |

## 使用示例

```sql
-- 查询某报告期全部债券投资风格标签
SELECT c_fd_code,
       c_bd_type_style,
       c_bd_type_timing,
       c_leverage_pref,
       c_leverage_timing,
       c_credit_pref,
       c_credit_timing,
       c_duration_pref,
       c_duration_timing
FROM tytdata.tb_fd_tag_bd_style
WHERE c_report_date = '2024-09-30';

-- 筛选高杠杆+信用下沉的基金
SELECT c_fd_code, c_leverage_avg, c_low_credit_avg
FROM tytdata.tb_fd_tag_bd_style
WHERE c_report_date = '2024-09-30'
  AND c_leverage_pref = '高杠杆'
  AND c_credit_pref = '信用下沉';

-- 定开基金的杠杆风格分布
SELECT c_leverage_pref, COUNT(*) AS cnt
FROM tytdata.tb_fd_tag_bd_style
WHERE c_report_date = '2024-09-30'
  AND c_is_locked = '1'
GROUP BY c_leverage_pref;
```
