# tb_fd_perform_abs - 基金绝对收益指标表

## 基本信息

- **表名**: `tb_fd_perform_abs`
- **主键**: (c_fd_code, c_trade_date, c_period_code)
- **更新频率**: 每日
- **说明**: 存储基金在不同时间区间的绝对收益表现指标,包括收益、风险和风险调整后收益等核心指标

## 字段清单

| 字段名             | 类型            | 注释           | 说明                        |
|-----------------|---------------|--------------|---------------------------|
| c_fd_code       | VARCHAR(20)   | 基金代码         | 六位基金代码                    |
| c_trade_date    | DATE          | 交易日期         | 计算截止日期                    |
| c_period_code   | VARCHAR(10)   | 计算区间代码       | 见枚举值                      |
| c_period_ret    | DECIMAL(10,4) | 区间收益率(%)     | 百分比形式,如25.5表示25.5%        |
| c_ann_ret       | DECIMAL(10,4) | 年化收益率(%)     | 百分比形式,年化后的收益率             |
| c_ann_vol       | DECIMAL(10,4) | 年化波动率(%)     | 百分比形式,正数,标准差年化            |
| c_up_side_vol   | DECIMAL(10,4) | 上行波动率(%)     | 百分比形式,正数,正收益的波动率          |
| c_down_side_vol | DECIMAL(10,4) | 下行波动率(%)     | 百分比形式,正数,负收益的波动率          |
| c_mdd           | DECIMAL(10,4) | 最大回撤(%)      | 百分比形式,正数,如25.5表示最大回撤25.5% |
| c_sharpe        | DECIMAL(15,4) | 夏普比率         | 风险调整后收益,(收益-无风险利率)/波动率    |
| c_calmar        | DECIMAL(15,4) | 卡尔玛比率        | 年化收益率/最大回撤                |
| c_sortino       | DECIMAL(15,4) | 索提诺比率        | (收益-无风险利率)/下行波动率          |
| c_skewness      | DECIMAL(10,4) | 偏度           | 收益率分布的偏斜程度                |
| c_kurtosis      | DECIMAL(10,4) | 峰度           | 收益率分布的尖峭程度                |
| c_break_ratio   | DECIMAL(10,4) | 净值创新高天数比例(%) | 百分比形式,区间内创新高天数占比          |
| c_updatetime    | DATETIME(6)   | 更新时间         | 自动更新时间戳                   |

| 02 | 近6月  | 近6个月   |
| 03 | 近1年  | 近1年    |
| 04 | 近2年  | 近2年    |
| 05 | 近3年  | 近3年    |

## 指标说明

### 收益指标

- **区间收益率**: 期间累计收益率,公式: (期末净值/期初净值 - 1) × 100
- **年化收益率**: 将区间收益率年化,公式: ((1 + 区间收益率)^(252/实际交易日数) - 1) × 100

### 风险指标

- **年化波动率**: 日收益率标准差年化,反映收益波动程度
- **上行波动率**: 仅统计正收益的波动,反映上涨时的不稳定性
- **下行波动率**: 仅统计负收益的波动,反映下跌风险
- **最大回撤**: 区间内净值从最高点到最低点的最大跌幅(正数表示)

### 风险调整收益指标

- **夏普比率**: 单位风险的超额收益,越高越好,一般>1为优秀
- **卡尔玛比率**: 年化收益与最大回撤的比值,越高越好
- **索提诺比率**: 类似夏普比率,但只考虑下行风险

### 分布特征指标

- **偏度**: 正值表示右偏(极端正收益多),负值表示左偏(极端负收益多)
- **峰度**: 大于3表示尖峰(极端值多),小于3表示平坦

### 其他指标

- **净值创新高天数比例**: 反映基金创造新高的频率,越高说明持续性越好

## 使用示例

### 查询某基金近1年表现

```sql
SELECT c_fd_code,
       c_trade_date,
       c_period_ret,
       c_ann_ret,
       c_ann_vol,
       c_mdd,
       c_sharpe,
       c_calmar
FROM tytdata.tb_fd_perform_abs
WHERE c_fd_code = '000001'
  AND c_period_code = '03'  -- 表示近一年
  AND c_trade_date = (SELECT MAX(c_trade_date)
                      FROM tb_fd_perform_abs
                      WHERE c_fd_code = '000001');
```

### 筛选夏普比率优秀的基金(近3年)

```sql
SELECT c_fd_code,
       c_ann_ret,
       c_ann_vol,
       c_sharpe,
       c_mdd
FROM tytdata.tb_fd_perform_abs
WHERE c_period_code = '05'
  AND c_trade_date = '2024-11-27'
  AND c_sharpe > 1.5
  AND c_mdd < 20
ORDER BY c_sharpe DESC
LIMIT 50;
```

### 对比不同时间区间表现

```sql
SELECT c_period_code,
       c_period_ret,
       c_ann_ret,
       c_sharpe,
       c_mdd
FROM tytdata.tb_fd_perform_abs
WHERE c_fd_code = '000001'
  AND c_trade_date = '2024-11-27'
  AND c_period_code IN ('00', '01', '02', '03', '05')
ORDER BY FIELD(c_period_code, '00', '01', '02', '03', '05');
```

## 注意事项

1. **数值单位**:
    - 收益率、波动率、回撤等均为百分比形式,已乘以100
    - 比率类指标(夏普、卡尔玛、索提诺)为纯数值,无单位

2. **正负约定**:
    - 最大回撤存储为正数(25.5表示回撤25.5%,而非-25.5)
    - 波动率均为正数
    - 收益率可正可负

3. **NULL值处理**:
    - 数据不足时(如成立不满1年的基金查1年期指标),相关字段为NULL
    - 波动率为0时,夏普/索提诺比率为NULL
    - 最大回撤为0时,卡尔玛比率为NULL

4. **计算频率**:
    - 每日收盘后计算更新
    - 历史数据支持时间序列分析

5. **无风险利率**:
    - 无风险利率设置为2%
