# tb_fd_holder_top10 — 基金前十大持有人明细表

## 概述

存储每只基金每个报告期前十大持有人的名称、类型、份额及比例，来源为 Oracle `FUND_HR_HOLDERTOP10`。

- **KEY**: `(c_report_date, c_fd_code, c_rank)`
- **表类型**: 视图（Oracle 实时映射，DBA 配置 catalog 后生效）
- **更新频率**: 半年报/年报披露后（c_style='02'/'04'）
- **基金范围**: 全量，含各份额，不做主代码去重

---

## 字段说明

| 字段 | 类型 | 说明 |
|---|---|---|
| `c_report_date` | DATE | 报告日期 |
| `c_fd_code` | VARCHAR(20) | 基金代码 |
| `c_rank` | NUMBER | 持有人名次（1–10） |
| `c_style` | VARCHAR(20) | 报表类别（见枚举） |
| `c_holder_name` | NVARCHAR(300) | 持有人标准名称（`SNAME`） |
| `c_holder_type` | VARCHAR(30) | 持有人类型（见枚举） |
| `c_hold_share` | FLOAT | 持有份额（份） |
| `c_hold_ratio` | FLOAT | 持有比例（%） |
| `c_notice_date` | DATE | 公告日期 |

---

## 枚举值

**c_style 报表类别**

| 值 | 含义 | 报告期 |
|---|---|---|
| `02` | 半年报 | 06-30 |
| `04` | 年报 | 12-31 |
| `07` | 非定期披露 | 非标准日期，仅 1999–2002 年早期封闭式基金，极少 |

**c_holder_type 持有人类型（主要分类）**

| 类型 | 说明 |
|---|---|
| 个人 | 自然人投资者 |
| 保险公司 | 寿险、财险等保险机构 |
| 保险产品 | 保险资管产品（万能险账户等） |
| 全国社保基金 | 社保基金理事会直投 |
| 企业年金 | 企业年金计划 |
| 信托计划 | 信托产品 |
| 集合理财计划 | 券商资管集合计划 |
| 银行个人理财产品 | 银行理财子产品 |
| 证券公司 | 券商自营 |
| 投资公司 | 各类投资公司/私募等 |
| 基金管理公司 | 公募基金公司自购 |
| 上市公司 | A股/H股上市主体 |
| 财务公司 | 集团财务公司 |
| 联接基金 | ETF 联接基金（指向同一底层 ETF） |
| 期货公司 | 期货公司资管 |
| 信托投资公司 | 信托机构 |
| 其它 | 其他未分类机构 |

## 注意事项

**A/C 份额各有独立记录**，分析机构偏好时建议区分份额类型（通过 `tb_fd_basic_info.c_short_name` 判断 A/C）。

**c_style='07' 的数据**：非定期披露，时间跨度从 1998 年至今（共 2.8 万条），涵盖 ETF 新上市、新发基金首次披露、清盘前强制披露等场景，现代 ETF 中较常见。`c_report_date` 为非标准日期。使用时若只需标准半年报/年报数据，过滤 `c_style IN ('02','04')`。

**c_rank 可超过 10**：`c_style='07'` 的披露有时会列出全量持有人而非仅前十大，名次字段可能远超 10（实测最高 130+），字段类型为 SMALLINT。

**c_holder_name 可能为 NULL**：源表 `SNAME` 字段在个别早期记录中为空，此时可参考原表 `NAME` 字段（本视图未映射）。
