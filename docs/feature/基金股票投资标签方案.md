## 股票投资风格标签方案

### 表结构总览

| 表名 | 维度 | 说明 |
|---|---|---|
| `tb_fd_tag_stk_region_sector` | 区域 + 板块 | 港股占比、六大板块权重及变动、标签 |
| `tb_fd_tag_stk_style` | 风格偏好 | 市值/价值-成长维度得分及标签 |
| `tb_fd_tag_stk_portfolio` | 组合构建 + 主动管理 + 交易特征 | 集中度、主动偏离、换手、重仓交易等 |
| `tb_stk_crowding_score` | 抱团度（个股级） | 全市场口径的个股抱团度 |

所有标签表 KEY = `(c_report_date, c_fd_code)`，抱团度表 KEY = `(c_report_date, c_stk_code)`。

---

### 表1: `tb_fd_tag_stk_region_sector`

**区域特征字段：**
- `c_hk_ratio_avg` — 近8期港股占比均值（%）
- 最新一期港股占比均值
- `c_region_tag` — A股 / 均衡 / 港股

**板块特征字段：**
- `c_sector_cycle` / `c_sector_mfg` / `c_sector_tech` / `c_sector_consumer` / `c_sector_pharma` / `c_sector_fin` — 六大板块权重均值（%）
- `c_sector_chg` — 板块权重变动指标（%）
- `c_sector_tag` — 均衡型 / 轮动型 / 赛道型
- `c_sector_pref` — 板块偏好（赛道型时填写，如"消费"；其余为空）

**配置文件：** `config/sector_mapping.yaml` — 中信一级行业 → 六大板块映射

---

### 表2: `tb_fd_tag_stk_style`

- `c_size_score` — 持仓加权总市值（原始值，亿元）
- `c_size_tag` — 大盘 / 中盘 / 小盘
- `c_vg_score` — 价值-成长维度得分
- `c_vg_tag` — 价值 / 均衡 / 成长

风格划分阈值每期动态计算（全市场股票市值排序），阈值本身不落表，在计算逻辑内处理。

---

### 表3: `tb_fd_tag_stk_portfolio`

**组合构建：**
- `c_sector_hhi` — 板块HHI
- `c_ind_hhi` — 行业HHI
- `c_ind_top5_ratio` — 前5大行业权重占比（%）
- `c_ind_concent_rank` — 行业集中度复合排名
- `c_top10_ratio` — 前10大持股权重占比（%）
- `c_sector_concent_tag` — 集中 / 均衡 / 分散
- `c_ind_concent_tag` — 集中 / 均衡 / 分散
- `c_stk_concent_tag` — 集中 / 均衡 / 分散

**主动管理：**
- `c_active_sector` — 主动板块配置偏离度
- `c_active_ind` — 主动行业配置偏离度
- `c_active_sector_rank` / `c_active_ind_rank` — 百分比排名
- `c_active_tag` — 主动配置 / 主动板块配置 / 主动行业配置 / 空
- `c_new_stk_ratio` — 持股扩新指标（%）
- `c_new_stk_tag` — 积极 / 适中 / 保守
- `c_crowd_score` — 全市场抱团度（基金级，从个股表加权聚合）
- `c_crowd_internal_score` — 同公司抱团度（基金级）

**交易特征：**
- `c_turnover_avg` — 换手率均值（倍，半年报前向填充）
- `c_turnover_tag` — 高换手 / 中换手 / 低换手
- `c_heavy_retain_rate` — 重仓股留存率均值
- `c_heavy_turnover` — 重仓股换手率均值
- `c_heavy_hold_period` — 重仓股持有期均值（期）
- `c_heavy_trade_rank` — 重仓交易复合排名
- `c_heavy_trade_tag` — 偏长期持有 / 持有期适中 / 偏短期交易

---

### 表4: `tb_stk_crowding_score`（个股级中间表）

KEY = `(c_report_date, c_stk_code)`

- `c_crowd_score_mkt` — 全市场抱团度
---

### 实现顺序建议

1. `config/sector_mapping.yaml` + `tb_fd_tag_stk_region_sector`（依赖最少）
2. `tb_fd_tag_stk_style`（需要个股风格得分计算）
3. `tb_stk_crowding_score`（个股级，被表3依赖）
4. `tb_fd_tag_stk_portfolio`（依赖抱团度表 + 基准指数权重）
