# 固收加季度报告设计思路

## 固收+基金季报解读——报告框架

### 一、市场环境回顾（定基调）
**目的：为后续分析提供背景**
- 权益市场表现：主要宽基指数涨跌幅（沪深300、中证500、创业板指、恒生指数等）
- 债券市场表现：国债收益率走势、信用利差变化
- 转债市场表现：中证转债指数涨跌幅、转债估值水平变化（转股溢价率等）
- 当季市场关键事件/驱动因素（政策、流动性、风险事件等）————AI生成回顾即可

### 二、规模变化（回答"市场有多大、钱往哪里去"）
**目的：刻画行业发展态势**

1. **总量概览**
   - 固收+基金总数量、总规模、环比/同比变化
   - 历史规模趋势图（标注关键节点）【各报告期】

2. **分品类拆解**
   - 按产品类型：一级债基、二级债基、偏债混合、灵活配置（低仓位）、转债基金、偏债FOF
   - 各品类规模变化及占比变化，识别哪个品类是主要增量来源

3. **按仓位/策略类型拆解**（可选，申万的做法）
   - 低仓位/中仓位/高仓位/过高转债仓位的规模变化
   - 细分权益策略（如固收+成长/科技/均衡/周期等）规模变化对比

4. **基金公司维度**
   - 管理规模TOP20排名及市占率
   - 规模增长TOP10基金公司及代表产品

5. **单产品维度**
   - 规模增长TOP20产品明细

6. **新发产品**
   - 新发数量、募资总规模、单只平均规模
   - 新发品类结构（二级债基/FOF/一级债基等占比）
   - 募集份额TOP10新发产品明细
   - （可选）与历史同期或上轮高峰（2021年）的新发结构对比

### 三、资金流向（回答"谁在买、谁在卖"）
**目的：识别增量资金来源与市场情绪**

1. **申赎总览**
   - 全市场固收+基金净申购总额
   - 分品类净申购/净赎回

2. **基金公司维度**
   - 净申购规模TOP10基金公司

3. **单产品维度**
   - 净申购规模TOP20产品明细

4. **投资者结构**（半年报/年报可用）
   - 机构vs个人持有比例变化
   - 机构偏好产品 vs 个人偏好产品的规模变动差异
   - （可延伸）增量资金来源判断：险资/年金/银行理财/零售端

### 四、业绩表现（回答"赚了多少、亏了多少"）
**目的：评估产品表现，识别优秀管理人**

1. **整体业绩**
   - 全市场固收+基金当季收益中位数、年初至今收益中位数
   - 正收益占比
   - 最大回撤中位数

2. **分品类业绩**
   - 各品类（一级债基/二级债基/转债基金/偏债混合/FOF等）收益及回撤分位数表
   - 收益分化程度（极差）

3. **分仓位/策略业绩**
   - 低/中/高仓位产品收益对比
   - 细分权益策略（成长/科技/均衡/周期等）收益排名

4. **基金公司维度**
   - 管理规模TOP20公司的平均收益、收益分化度

5. **绩优产品**
   - 各品类收益TOP5产品明细（规模>1亿元筛选）
   - 大规模产品业绩盘点（规模TOP20的业绩表现及同类排名）

### 五、持仓配置分析（回答"买了什么、怎么调的"）
**目的：把握基金经理集体判断方向**

1. **大类资产配置**
   - 各品类股票仓位变化（中位数，时间序列对比）
   - 各品类转债仓位变化
   - 权益整体仓位变化（股票+0.5×转债）

2. **股票持仓**
   - 重仓股行业分布及季度增减持（分品类展示）
   - 板块维度汇总（金融/科技/制造/消费/周期/医药）
   - 港股仓位变化
   - 前十大重仓股明细（分品类）
   - （可选）基金公司维度行业超低配对比

3. **转债持仓**（可独立成一节或合并）
   - 转债持仓总规模及占比变化
   - 信用评级分布（AAA/AA+/AA等）
   - 行业分布及增减持
   - 与全市场转债结构的超配/低配对比
   - 前20大重仓转债明细
   - 增持/减持TOP10转债

4. **绩优产品配置特征**（可选）
   - 当季业绩靠前产品的行业配置共性

### 六、热点专题（可选，提升报告辨识度）
**目的：提供差异化观点**

根据当季市场特点选一个切入角度，例如：
- "固收+成长"策略的时代是否到来
- 机构资金驱动下的"赛道型固收+"崛起
- 险资增配二级债基的逻辑与影响
- 新发产品结构变迁的启示

### 七、总结与展望
- 当季核心发现提炼（3-5条）
- 后市策略方向建议（权益策略偏好、仓位建议、关注品类）
- 增量资金结构判断


## 执行计划

### 整体思路

1. **先建数据层**：每个模块拆成独立的数据取数任务，输出标准化表格
2. **再建图表层**：基于数据表自动生成图表
3. **最后填报告模板**：定量部分自动填充，定性部分（点评、展望）手动撰写

报告期参数化：所有取数任务用 `report_date`（如 `2025-12-31`）和 `prev_date`（如 `2025-09-30`）作为输入参数，换季只改参数。

### 模块三：资金流向

**数据任务 3-1：申赎数据**

每只基金一行（排除本季新成立）：

| 字段 |
|---|

### 落地节奏建议

| 步骤 | 内容 | 产出 |
|---|---|---|
| **Step 1** | 确定固收+基金样本池筛选规则，建基础表（任务2-1） | 基金清单CSV |
| **Step 2** | 并行取数：规模、申赎、业绩、仓位、重仓股、转债持仓 | 各模块数据表 |
| **Step 3** | 写汇总统计+图表生成代码（参数化） | Python脚本/Jupyter |
| **Step 4** | 建报告模板（Word/Markdown），标注数据填充位 | 模板文件 |
| **Step 5** | 四季报数据跑通全流程 | 完整报告V1 |
| **Step 6** | 一季报更新参数，重跑 | 完整报告V2 |

**关键设计原则**：
- 所有取数任务的输入只有 `report_date` 和基金清单
- 汇总统计和图表代码不硬编码任何日期
- 报告模板中定量部分用占位符（如 `{{total_scale}}`），自动替换
