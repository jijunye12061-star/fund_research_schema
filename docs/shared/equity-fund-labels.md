# 权益基金标签体系说明

主动权益基金（001001）的三张标签表，覆盖**风格、区域/板块、组合特征**三个维度。
汇总查询见 `docs/shared/equity_fund_labels.sql`，修改顶部 `WITH param` 的日期和 style 即可切换报告期。

> **建议报告期**：06-30 / 12-31（半年报/年报期，全部字段有正式计算值）  
> 03-31 / 09-30 也可查，但依赖全持仓的字段（换手率、抱团度、持股扩新等）为前向填充值。

---

## 一、风格标签（tb_fd_tag_stk_style）

**定位**：回答"找大盘价值基金"、"哪些基金高动量"。

**基金范围**：主动权益（001）+ 固收加（002）+ 混合（004），仅主代码去重。

### 数据基础与加权方式

- 持仓：近 **4期半年报**（06-30 / 12-31），仅A股（港股标的通过与 `tb_stk_barra_status` inner join 自动剔除）
- 因子：`tb_stk_risk_factor`（VALUE/GROWTH/MOMENTUM/PROF/QUALITY/DTOP），取报告期对应的最近交易日
- **加权权重**：个股**持仓市值**（`c_hold_value`）——反映基金实际配置比重

各期单独计算持仓加权因子得分，再对4期求**均值**作为最终分数。

### 市值标签（c_size_tag）

分两步：先从市场确定阈值，再与基金得分比较。

**第一步：从全市场A股确定阈值（每期独立计算，4期均值）**

全市场A股按流通市值降序累加：
- `size_50`：累积市值刚过 50% 时，边界股票的流通市值（亿元）
- `size_70`：累积市值刚过 70% 时的边界值

取4期均值得最终阈值 `avg_50` / `avg_70`。

**第二步：计算基金得分并打标签**

基金市值得分 = 持仓市值加权的个股流通市值（亿元），4期均值。即：每只持仓股的流通市值按持仓市值加权平均，再平均4期。

| 取值 | 条件 |
|------|------|
| 大盘 | 基金得分 > avg_50 |
| 中盘 | avg_70 < 基金得分 ≤ avg_50 |
| 小盘 | 基金得分 ≤ avg_70 |

> 阈值来自全市场股票，反映市场真实的大/中/小盘分界线，不是基金之间相互比较。

### 价值-成长标签（c_vg_tag）

同样两步：先从全市场股票确定阈值，再判断基金。

全市场各股 spread = VALUE − GROWTH 的 67%/33% 分位（4期均值）作为阈值。

基金的 value_score / growth_score = 持仓市值加权的 Barra 因子 z-score，4期均值。

| 标签 | 判断规则（按优先级） |
|------|---------|
| 价值 | value_score > 0，且 (value_score − growth_score) ≥ 市场67%分位阈值 |
| 成长 | growth_score > 0，且 (value_score − growth_score) ≤ 市场33%分位阈值 |
| GARP | value_score > 0 且 growth_score > 0，不满足上两条 |
| 均衡 | 其余情况（两者都不显著偏高） |

> VALUE 因子高 = 低估值（低PE/低PB），不代表"好公司"。高PE白酒基金通常被打成"成长"而非"价值"，这是正确结果。

### 动量 / 盈利 / 质量 / 红利标签

**按基金类型（001/002/004）分别排名**，在各类型内部排除港股基金后，取 70%/30% 分位切三档。即：001 主动权益基金内部比较，004 混合基金内部比较，002 固收加内部比较，三组互不影响。

| 取值 | 条件 |
|------|------|
| 高xxx | 得分 ≥ 同类型非港股基金的70%分位 |
| 中xxx | 30%分位 < 得分 < 70%分位 |
| 低xxx | 得分 ≤ 30%分位 |

**港股基金**（`c_region_tag = '港股'`）的动量/盈利/质量/红利标签为 NULL：港股标的无 Barra 因子数据，仅用极少A股持仓算出的得分与纯A股基金不具可比性。

### 风格稳定性标签（c_stability_tag）

衡量基金在4期内**市值风格和价值-成长风格是否稳定**。

- 计算4期内市值得分的标准差（`size_std`）和 value−growth spread 的标准差（`vg_std`）
- 将两个标准差分别在**同期全量非港股基金内**做百分比排名，取均值得 `c_stability_score`（0~100）
- 排名越低代表波动越小、风格越稳定

| 取值 | 条件 |
|------|------|
| 稳定 | stability_score < 30 |
| 适中 | 30 ≤ stability_score ≤ 70 |
| 漂移 | stability_score > 70 |

港股基金及历史数据不足2期的基金为 NULL。

## 二、区域/板块标签（tb_fd_tag_stk_region_sector）

**定位**：回答"找港股基金"、"哪些基金是科技赛道"、"基金板块配置是否轮动"。

### 区域标签（c_region_tag）

基于近 **8期季报**港股占股票仓位均值（`c_stk_hk_connect_ratio / c_stk_total_ratio`）：

| 标签 | 条件 |
|------|------|
| A股 | 港股仓位均值 < 20% |
| 均衡 | 20% ≤ 均值 ≤ 60% |
| 港股 | 均值 > 60% |

### 板块标签（c_sector_tag / c_sector_pref）

基于近 **4期半年报**行业权重（`tb_fd_ind_weight`），中信一级行业归为六大板块：
科技、消费、医药、中游制造、周期、金融地产。

**第一步：计算板块配置变动指标 `c_sector_chg`**

各板块权重均值 × 各板块权重变化幅度均值，再按板块权重加权汇总。值越大说明板块轮动越频繁。

**第二步：打标签（按优先级顺序）**

| 标签 | 判断条件 | 含义 |
|------|---------|------|
| 轮动型 | chg ≥ 20%，且调整后最大板块均值 ≤ 50% | 板块切换明显，无持续主导板块 |
| 赛道型 | 最大板块均值 > 50%（且非轮动型） | 长期重仓单一板块 |
| 均衡型 | 其余 | 配置分散且稳定 |

赛道型基金同时输出 `c_sector_pref`（科技/消费/医药/中游制造/周期/金融地产之一）。

## 三、组合特征标签（tb_fd_tag_stk_portfolio）

**定位**：回答"基金是否集中押注"、"换手率高低"、"持股是否独特"、"是否抱团"。

**阈值机制**：所有相对标签均按**基金类型（001/002/003/004）分别排名**，70%/30%分位切三档。

### 集中度

| 标签 | 数据来源 | 构造方式 |
|------|---------|---------|
| c_sector_concent_tag | 近4期半年报板块权重 | 板块 HHI（权重归一化后平方和）按类型排名 |
| c_ind_concent_tag | 近4期半年报行业权重 | 行业 HHI + 前5大行业占比，复合排名 |
| c_stk_concent_tag | 近8期季报前十大持股 | 前十大持股占股票仓位比例（排除仓位高低影响）按类型排名 |

三档均为：**集中 / 均衡 / 分散**。

### 主动管理

| 标签 | 含义 |
|------|------|
| c_active_tag | 相对中证800的偏离程度：板块偏离和行业偏离（板块内归一化后比较）均高 → 主动配置；否则区分主动板块配置/主动行业配置 |
| c_new_stk_tag | 持股扩新率：当期全持仓中未出现在前3期的权重占比，积极（≥50%）/ 适中（≥20%）/ 保守（<20%） |
| c_crowd_tag | 抱团度：全市场个股热度得分加权均值（`tb_stk_crowding_score`）+ 同公司内部持仓重叠度，复合排名，高抱团/中抱团/低抱团 |

### 交易特征

| 标签 | 含义 |
|------|------|
| c_turnover_tag | 换手率均值（来自 `tb_fd_turnover`），按基金类型排名，高换手/中换手/低换手 |
| c_heavy_trade_tag | 重仓交易风格：综合重仓留存率、重仓换手率、重仓持有期三个指标复合排名，**偏长期持有 / 持有期适中 / 偏短期交易** |

## 字段数据状态对照

| 字段 | 正式值报告期 | 季报期（03-31/09-30）行为 |
|------|------------|-------------------------|
| 市值/风格/动量/盈利/质量/红利/稳定性 | 每期更新（取最近4期半年报窗口） | 同半年报期（Q1/Q3共享相邻Q2/Q4的4期窗口，结果相同） |
| 区域标签 | 每期更新（8期季报均值） | 正常更新 |
| 板块标签 | 半年报/年报后正式计算 | 前向填充上期值 |
| 集中度/主动偏离/抱团度/换手率 | 半年报/年报后正式计算 | 前向填充上期值 |
| 前十大持股集中度（c_stk_concent_tag）、重仓交易系列 | 每期更新（8期季报均值） | 正常更新 |
| 持股扩新（c_new_stk_tag） | 半年报/年报后正式计算 | 前向填充上期值 |
